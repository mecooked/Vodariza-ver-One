## 🔹 О проекте | ...(*￣０￣)ノ

Одностраничный лендинг для бренда Водарица. Водарица — это вода, добытая из уникального природного источника в экологически чистом регионе Абхазии, у легендарного озера Рица. 
Главная фишка проекта - *тематические анимации на GSAP*:
* Плавный скролл с ScrollSmoother;
* Параллакс через data-speed - изменение скорости пролистывания разных элементов;
* Анимации методом gsap.from, где указывается конечное положение с атрибутами анимации. Множество анимаций для исключения повторения одного и того же кода сделаны через фабричный метод. Есть одна функция и при её вызове подставляются значения для выбранного элемента
